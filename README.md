# Çok Ciddi Kahve Falı Makinesi

Bu repository, Türkiye Cumhuriyeti Bilim ve Kahve Araştırmaları Enstitüsü tarafından onaylanmış (asla onaylanmamıştır), dünyanın en akademik, en metodolojik, en aşırı ciddi kahve falı yorumlama algoritmasını içerir.

## Nedir Bu?

Sıradan falcılar fincana bakıp "yolun açık" der. Biz ise fincanın geometrik yapısını, kahve tortusunun Brownian hareketini ve kullanıcının ruhsal frekansını hesaplayarak gelecek projeksiyonu yaparız.

**Patates yoktur. Asla patates yoktur.**

## Nasıl Kullanılır?

```bash
python fal_makinesi.py
```

Fincanınızı tarif edin. Örneğin: "Fincanımda büyük bir daire ve üç nokta var, biraz bulanık."

Algoritma size hayatınızın geri kalanını özetleyecektir.

## Bilimsel Temel

- Kahve tortusu entropisi
- Fincan geometrisi analizi
- Rastgele sayı üreticisi (kaderin ta kendisi)

## Lisans

Bu yazılım "ne olursa olsun" lisansı altındadır. Kullanırken sorumluluk size aittir. Eğer fal kötü çıkarsa, kahveyi değiştirin.
